# If Else

Para a execução do exercício do If Else, usei como base o exemplo que o professor deixou na aula 3. Recorri a várias funções que se encontram na biblioteca do p5.js, pois dá para ir experimentando de forma a melhor compreendê-las, sendo que todas são acompanhadas de uma explicação teórica.
Dividi o ecrã apenas em 2 metades: uma rosa com linhas horizontais brancas, a outra azul com linhas verticais pretas – aqui aplica-se um if/else, dependendo de onde o rato se encontra no ecrã. Defini movimento como uma variável, para mais tarde o input/interação de mouseIsPressed funcionar conforme planeado.
As variáveis let distância e let espessura, usam as funções dist e map de p5.js. Nestas funções particularmente, precisei do auxílio de ferramentas de inteligência artificial (no caso o ChatGPT) para que funcionassem corretamente. A dist vai calcular a distância entre dois pontos. A map converte um valor de um ponto ao outro. A função constrain, também de p5.js, vai-nos limitar a espessura entre 1 px a 15 px (no caso do lado rosa) e 1 px a 22 px (no caso do lado azul). Este bloco de código, vai permitr que a espessura das linhas mude ao mexer o cursor, mesmo quando estamos a pressionar o rato e as linhas estão em movimento.
Aquando if (mouseIsPressed) vai provocar o movimento das linhas. As linhas horizontais movem para baixo, enquanto que as linhas verticais movem para o lado direito.
Para fazer as function(s) para as linhas, também precisei do auxílio do ChatGPT.  O for serve para desenhar as linhas em repetição: para que comecem a aparecer “antes do início” do canvas, e que continuem até “depois do final”, com intervalos de 17px por ciclo (loop). O mesmo se aplica para as linhas verticais, mas muda o espaçamento e passamos a falar do x em vez de y. A line vai definir onde começa e termina a linha, e as suas posições iniciais e finais quando se movem. O movimento das linhas foi definido como 2, e usamos o % (módulo), que nos dá o resto de uma divisão. No caso das linhas horizontais, o deslocamento das mesmas está sempre entre 0 e 16, e no caso das linhas verticias entre 0 e 49. Esta parte foi uma das mais difíceis de compreender, mas ao perceber a teoria e ir fazendo experiências tentativa-erro no p5.js, acabei por compreender!
